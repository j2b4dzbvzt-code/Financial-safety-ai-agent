# 附录 G：参考课程中 25 类安全应用的唯一完整索引

> 课程安全应用条目来自用户先前学习资料。本表用于把 GenAI 与传统检测技术的角色区分清楚，正文不再复制 25 项列表。

| # | 英文术语 | 中文任务 | 核心技术 | 生成式 AI 适宜任务 |
|---:|---|---|---|---|
| 1 | Real-time threat detection | 实时威胁检测 | 流处理、规则/ML | 对告警给出证据摘要 |
| 2 | Anomaly detection | 异常检测 | UEBA、统计、序列模型 | 解释异常及正常替代假设 |
| 3 | Automated incident response | 事件响应自动化 | SOAR 及授权工作流 | 建议步骤和人工确认 |
| 4 | Security event correlation | 事件关联 | SIEM 多源规则 | 时间线与关联假设 |
| 5 | Predictive threat intelligence | 预测威胁情报 | 历史风险与威胁情报 | 识别情报缺口 |
| 6 | Automated threat hunting | 自动化威胁狩猎 | 可证伪假设与受控查询 | 生成只读调查计划 |
| 7 | User behavior analytics | 用户行为分析 | UEBA 同群组基线 | 解释角色与时点背景 |
| 8 | Fraud detection | 欺诈检测 | 分类、图分析与异常评分 | 案件摘要、证据归属 |
| 9 | Malware detection | 恶意软件检测 | EDR、YARA、沙箱 | 解释进程与文件行为 |
| 10 | Security incident response orchestration | 响应编排 | SOAR Playbook | 生成工单和补救建议 |
| 11 | Insider threat detection | 内部威胁检测 | UEBA、DLP、权限事件 | 结合授权背景避免无根据归责 |
| 12 | Threat intelligence analysis | 威胁情报分析 | IOC/TTP/ATT&CK | 情报聚合和引用 |
| 13 | Automated log analysis | 自动日志分析 | SIEM、统计、结构化查询 | 自然语言解释查询结果 |
| 14 | Vulnerability management | 漏洞管理 | 漏洞扫描、CVSS/EPSS/KEV | 修复优先级解释 |
| 15 | Security incident visualization | 安全事件可视化 | 事件时间线/图关系 | 图表摘要与结论限界 |
| 16 | Automated phishing detection | 钓鱼检测 | 邮件认证、URL、附件分析 | 社会工程学解释 |
| 17 | Threat hunting collaboration | 协作威胁狩猎 | 跨角色共享调查记录 | 整理未决问题和证据 |
| 18 | Network traffic analysis | 网络流量分析 | NDR、流量统计 | 异常连接解释 |
| 19 | Automated malware response | 恶意软件自动响应 | EDR/SOAR授权隔离 | 处置手册草案 |
| 20 | Cloud security management | 云安全管理 | CSPM、IAM、云审计 | 权限变更和风险摘要 |
| 21 | Incident forensics | 事件取证 | 保全、哈希、时间线 | 取证记录摘要 |
| 22 | Threat hunting automation | 威胁狩猎持续自动化 | 规则库、定期狩猎 | 持续狩猎结果梳理 |
| 23 | Data loss prevention | 数据防泄漏 | DLP、分类与流量监控 | 敏感内容误报复核 |
| 24 | Endpoint detection and response | 终端检测与响应 | EDR 进程与遥测 | 调查协作 |
| 25 | Security compliance monitoring | 安全合规监控 | 政策与控制证据 | 合规材料汇总而非自动认证 |

**提示：**网络安全检测的主体仍是规则、统计/机器学习、威胁情报和专业安全产品；LLM 擅长对证据的组织、检索、摘要和解释，但不能自动替代取证、授权或业务风控。

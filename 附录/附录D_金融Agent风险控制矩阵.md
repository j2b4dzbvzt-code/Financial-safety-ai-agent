# 附录 D：金融 Agent 风险控制矩阵（RCM）与评价底稿

## 使用方式

- **控制设计验证**：理解为什么需要该控制、控制点是否覆盖真实 API 边界。
- **运行有效性验证**：检查其是否按批准版本持续执行、失败是否会告警。
- **实质性检验**：核对业务最终状态，绝不只看 UI 的绿灯或模型的解释。
- **异常处置**：记录阻断、证据保全、范围评估、修复、回归验证和批准恢复。

| ID | 风险事件 | 控制目标 | 预防控制 | 控制测试 | 细节/实质性核验 | 关键证据 | 失效处置 |
|---|---|---|---|---|---|---|---|
| R01 | 未授权账户交易 | 任何交易必须属于授权账户 | IAM scope + deny-by-default | 跨账户请求应被拒绝 | 逐笔核对交易账户与批准主体 | 权限快照、订单回执 | 停交易/撤销令牌 |
| R02 | 超单笔限额 | 单笔不超过限额 | 确定性订单名义额门禁 | 边界值与超限拒绝 | 核对已发出订单及有效限额 | 策略版本、成交 | 停机/评估敞口 |
| R03 | 并发突破累计额度 | 累计风险预留原子一致 | 事务/锁与原子预留 | 并发 10 笔不同订单 | 按账户独立重算日内额度 | 预留账本、日志 | 冻结额度/对账 |
| R04 | 重复订单 | 重试不能重复执行 | 全局幂等键及订单状态机 | 超时+重复调用 | 对账 OMS、券商与资金 | 订单 IDs、回执 | 查询权威状态 |
| R05 | 价格或行情过期 | 用可交易且新鲜报价 | known_time 与报价时效 | 旧报价/未来报价拒绝 | 逐笔比对成交时行情 | 行情快照 | 停策略/换权威数据 |
| R06 | 未批准高风险订单 | 审批绑定精确参数 | 独立审批签名 | 审批后篡改数量 | 抽样核对审批与执行参数 | 批准单、签名哈希 | 隔离审批流程 |
| R07 | 文档注入改规则 | 资料不可授予权限 | 工具边界与规则存储隔离 | 恶意研报提示注入 | 检查限额变更记录 | 研报哈希、策略审计 | 封存文档/撤权限 |
| R08 | RAG 跨租户泄露 | 仅检索有权资料 | 强 ACL 与分区索引 | 跨账户检索 | 复核返回结果与授权 | 索引快照、IAM | 撤销链接/隔离索引 |
| R09 | 数据前视偏差 | 只用决策时点已知数据 | point-in-time 审核 | 注入晚发布财报 | 比对回测依赖数据 | known_time、版本 | 撤销回测结论 |
| R10 | 多 Agent 权限放大 | 委托不扩大原授权 | 短期 scoped 能力令牌 | 下游越权请求 | 复核跨 Agent 消息链 | trace_id、令牌 | 撤销链路/重配权限 |
| R11 | 订单与持仓不一致 | 权威回执和账本一致 | 三方对账和异常队列 | 伪造缺失成交回执 | 逐笔复算金额/持仓/现金 | OMS、券商、账本 | 停新单/人工核对 |
| R12 | 滥用支付功能 | 双人复核且验证收款人 | Maker-Checker + 受益人白名单 | 无审批/换受益人拒绝 | 核对支付账本与批准单 | 支付流水、审批 | 冻结待支付/升级 |
| R13 | 模型漂移导致异常交易 | 性能和风险均可检测 | 持续监测与降级门槛 | 数据分布/价格冲击测试 | 按时段独立重算损失 | 指标、训练版本 | 降额/回退模型 |
| R14 | 日志被篡改 | 重要事件可追溯 | 独立存储、哈希链、签名 | 改动历史日志 | 跨来源核对时点/事件数 | 日志链、WORM | 证据保全/扩大调查 |
| R15 | 自动停机不能生效 | 必要时可立即停止风险 | 独立 Kill Switch | 触发停机后下单 | 核对停机期间的真实订单 | 停机指令、订单 | 隔离执行权限 |
| R16 | 供应链污染 | 依赖可信且可复现 | 签名构建/SBOM/锁依赖 | 篡改配置与升级回滚 | 检查部署版本与批准单 | SBOM、镜像签名 | 回滚/隔离依赖 |

## 标准工作底稿模板

| 字段 | 填写指南 |
|---|---|
| 工作底稿编号 | 对应风险 ID / 评价场景 ID |
| 风险与控制目标 | 不应只是“AI 不可靠”，要有可验证不变量 |
| 控制所有人 | 有权限调整控制的责任人 |
| 评估期间 | 明确开始、结束、时间戳口径 |
| 总体与抽样 | 全量/抽样，说明总体完整性和选择依据 |
| 测试前置条件 | 概念性环境、账户、策略、数据版本、工具权限 |
| 操作步骤 | 输入、检查路径、预期/实际、异常路径 |
| 结论 | 通过/失败/证据不足，不用模型自评替代事实 |
| 缺陷整改 | 负责方、风险缓解、期限、复测结果 |

> 注意：金融 Agent 验证用于安全与风控工程，不意味着对外签发财务报表审计意见。

> 这份矩阵是全文唯一的集中控制项速查表，章节讨论机理，不再复写此表。

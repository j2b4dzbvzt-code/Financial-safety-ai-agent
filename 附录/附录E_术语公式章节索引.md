## 公式阅读约定

- 使用 `$...$` 与 `$$...$$`，适配 GitHub Markdown 的数学公式渲染。
- 明确收益或损失的正负方向；VaR/ES 必须注明期限与分布口径。
- 上标 `\mathrm{known\_time}` 是数据时间语义，不等同于报告期。
- 数学约束用于解释风险控制原理，不能替代实时行情、权限和交易所规则。
